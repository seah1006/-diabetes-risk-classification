## FIX-02 `[CRITICAL]` — 위험 임계값 0.3/0.6 근거 추가 및 섹션 순서 수정

**파일:** `notebooks/04_decision.ipynb` 섹션 2, 섹션 5

**문제 1 — 순서 역전:**
현재 순서: 임계값 설정(섹션 2) → 위험 분류 → 정책 시나리오 → 임계값 트레이드오프 분석(섹션 5).  
임계값을 먼저 설정하고 나중에 그 임계값의 타당성을 분석하는 건 논리적으로 역전이다.  
정책 대상 인원(고위험 25.6%)이 이 임계값에 직접 의존하므로 발표에서 반드시 질문이 나온다.

**문제 2 — 근거 없는 임계값:**
```python
if prob >= 0.6: return '높음'
elif prob >= 0.3: return '중간'
```
0.3과 0.6의 선택 근거가 없다.

**수정 방법:**

섹션 2 앞에 마크다운 셀을 추가한다:

```markdown
## 임계값 선택 근거

로지스틱 회귀 기본 임계값(0.5)을 기준으로 Precision-Recall 트레이드오프를 확인한 후
세 구간으로 분류한다.

- **낮음 (< 0.3)**: 모델이 당뇨 가능성을 낮게 평가. 일반 건강 관리 권고.
- **중간 (0.3 ~ 0.6)**: 경계 구간. 생활 습관 개선 개입 대상.
- **높음 (≥ 0.6)**: 모델이 당뇨 가능성을 높게 평가. 정기 검사 및 집중 관리 대상.

임계값 0.3/0.6은 Precision-Recall 곡선 분석(섹션 5)에서 F1 최대 임계값과
Recall 0.8 보장 임계값을 함께 참고하여 설정한 값이다.
Recall 중심 기준(미탐지 비용 > 오탐지 비용)에 따라 0.3을 중간 구간 하한으로 채택했다.
```
